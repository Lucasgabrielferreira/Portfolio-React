<h1>Portfolio</h1>

<h2>Motivação</h2>
<p>Sempre quis ter um repositório centralizado para mostrar meu trabalho e facilitar o compartilhamento do meu portfólio com recrutadores e colaboradores. Este projeto reflete minha jornada no desenvolvimento e aprimoramento de aplicações web modernas.</p>

<h2>Tecnologias Utilizadas</h2>
<ul>
    <li>React</li>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

<h2>Funcionalidades</h2>
<ul>
    <li>Apresentação de projetos</li>
    <li>Informações sobre minhas habilidades</li>
    <li>Links para redes sociais e contatos</li>
</ul>

<h2>Como Rodar o Projeto</h2>
<ol>
    <li>Clone o repositório:
        <pre><code>git clone https://github.com/Lucasgabrielferreira/Portfolio-React.git</code></pre>
    </li>
    <li>Acesse a pasta do projeto:
        <pre><code>cd Portfolio-React</code></pre>
    </li>
    <li>Instale as dependências:
        <pre><code>npm install</code></pre>
    </li>
    <li>Inicie o servidor de desenvolvimento:
        <pre><code>npm start</code></pre>
    </li>
</ol>
